# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

PharmaLens (`pharmalens` package) is a Flutter app that reads prescriptions and acts as a medicine safety assistant for Lebanon. It targets Android, iOS, web and desktop, and supports English and Arabic (RTL).

## Commands

```bash
flutter pub get
flutter run                                    # dev; see "Secrets" for keys
flutter run --dart-define=GEMINI_API_KEY=...  # instead of lib/private/api_keys.dart
flutter analyze                                # flutter_lints is enabled; keep it at "No issues found"
flutter test
flutter test test/medicine_data_test.dart --plain-name "bundled MOPH list loads completely with ingredients"
flutter gen-l10n                               # after editing lib/l10n/*.arb
python tools/update_moph_dataset.py      # fetch the newest MOPH sheet and rebuild the CSV if it changed (needs `pip install xlrd`)
```

- **Android:** Gradle 8.14 does not run on Java 25. Point Flutter at JDK 17 (`flutter config --jdk-dir=...`), or run `android/gradlew` with `JAVA_HOME` set to JDK 17.
- **Windows desktop:** builds need Windows Developer Mode, for plugin symlinks.
- **Web links:** `/?tab=doctors` opens a section, and `/?tab=medicines&medicine=<MOPH code>` opens a medicine page. Both are handy for headless screenshots of `build/web`.

## Secrets

`lib/private/*.dart` is git-ignored. Copy the committed `*.example.dart` templates. Run `git config core.hooksPath .githooks` once per clone: the pre-commit hook blocks any staged Google/Gemini key (the repo is public). For CI or Play Store builds on another machine, pass keys with `--dart-define=GEMINI_API_KEY=...` instead of the file. Keys needed: Gemini (`api_keys.dart`) and Google Places (`google_maps_private_config.dart`, nearby places and hospital contacts). No Maps SDK key: the map does not use Google. Never print key values or commit them.

## Architecture

**Shell ([lib/app/app_shell.dart](lib/app/app_shell.dart)):** a bottom `NavigationBar` below 720 px, a `NavigationRail` up to 1100 px, and a sidebar above that. Breakpoints live in [lib/widgets/responsive.dart](lib/widgets/responsive.dart), alongside `PageFrame`, `AdaptiveGrid`, `SurfaceCard` and `AdaptiveBackButton`.
- Each tab has its own `Navigator`, and tabs are built lazily on first visit. Pushed pages (analysis, medicine details) stay beside the sidebar on desktop.
- Switch sections through `AppShellScope.maybeOf(context)?.selectTab(...)`.
- On phones, Settings is pushed rather than shown as a tab.
- Screens must work both as a tab root (no back button) and as a pushed page. Use `AdaptiveBackButton` or `Navigator.canPop`.

**Startup ([lib/main.dart](lib/main.dart)):** there is no backend. `MophMedicineService` and `DoctorsService` parse their bundled CSVs in a background isolate (`compute`). Neither throws; they expose `loadError` instead. Connectivity, history, allergies and reminders load in the background.

**Data: official sources only, never invented.**
- **Medicines:** `assets/medicines/lebanon_medicine_prices.csv` is generated by [tools/build_medicine_dataset.py](tools/build_medicine_dataset.py) from the MOPH Drugs Public Price List (XLS) joined with the Lebanon National Drug Index (ingredients, ATC).
  - Rows are keyed by MOPH code (`medicine_id`). List fields use `|`, and fields contain no newlines, because the CSV is parsed line by line.
  - `MophMedicineService` dedupes by code, so it keeps every strength and pack of a brand.
  - **Automatic updates:** [.github/workflows/update-moph-prices.yml](.github/workflows/update-moph-prices.yml) runs [tools/update_moph_dataset.py](tools/update_moph_dataset.py) every 6 hours. It finds the newest `WebMarketed*.xls` on the MOPH page (re-issues carry a second date, e.g. `WebMarketed20261005-19-10-2026.xls`), rebuilds the CSV, rejects suspicious builds, and commits the CSV with `lebanon_medicine_prices.json` (version, `published`, row count).
  - The app downloads from `MophMedicineService.dataBaseUrl` (raw GitHub by default; `--dart-define=MOPH_DATA_BASE_URL=`). `startAutoUpdates()` checks the manifest at most hourly, plus on reconnect, on app resume and on Sync; the CSV is fetched only when the manifest is newer and must match its row count. Downloaded lists are saved to a file (browser storage on web), and `datasetRevision` notifies the UI.
  - The app's base URL must be publicly readable. If the repo is private, set the workflow's `DATA_REPO` variable and `DATA_REPO_TOKEN` secret to mirror the files to a public repo, and point `MOPH_DATA_BASE_URL` there.
- **Equivalence:** [lib/utils/medicine_equivalence.dart](lib/utils/medicine_equivalence.dart) defines "same ingredient / strength / form" and compares prices per tablet, ml or g. Alternatives, the cheapest-equivalent list and safety checks all build on it.
- **Doctors:** `assets/doctors/lebanon_doctors.csv` comes from the Lebanese Order of Physicians list. It has name, code, specialty and hospital only: no gender, phone or address.
  - Gender is estimated from the Arabic first name by [lib/utils/doctor_gender_resolver.dart](lib/utils/doctor_gender_resolver.dart), and `Doctor.genderEstimated` is set. Unisex names stay unknown.
  - Hospital phone and location are looked up at runtime through Google Places (`HospitalContactService`) and cached for 30 days.
- **Patient information** (uses, how to take, side effects, warnings): the MOPH list has none, so [lib/services/medicine_info_service.dart](lib/services/medicine_info_service.dart) builds it at runtime.
  - It takes the openFDA drug label with the same ingredients, route, form and (preferably) strength, maps INN names to US ones (`paracetamol` → `acetaminophen`), and has Gemini summarize it in English and Arabic. With no matching label, Gemini writes it from general knowledge.
  - The page always labels the origin (`MedicineInfoOrigin`): AI summary of an FDA label, raw FDA label (no Gemini key), or AI-written. Keep that label; never present this text as reviewed or official.
  - Doses are only stated for the product's own strength. Results are cached in SharedPreferences per ingredients + form family + strength.
  - On a scanned medicine, "How to use" shows the doctor's written directions first; without them it says to ask the doctor, then the usual use.

**Prescription pipeline ([lib/screens/analysis_screen.dart](lib/screens/analysis_screen.dart)):**
1. OCR runs (ML Kit; skipped on web).
2. `AiHandwritingService` transcribes the image with Gemini, trying each model in `GeminiPrivateConfig.geminiModels` within a 100 s total budget (35 s per request).
3. `MedicineVerificationService` matches the transcription to MOPH products.
4. `MedicationSafetyService` flags allergies (by ingredient or ATC class), duplicate ingredients and same-class pairs.
5. The scan is saved on the device by `PrescriptionHistoryService`.

The design rule is that **Gemini only transcribes**. Identity, prices and safety come from registry data.

**Gemini ([lib/services/gemini_client.dart](lib/services/gemini_client.dart)):** the one place for keys, model order and `generationConfig`. Gemini 3 models get `thinkingLevel: low` and no temperature: their default high thinking, or a temperature below 1.0, made scans slow or cut off (thinking tokens count toward `maxOutputTokens`). Every Gemini caller (scan, chatbot, medicine info) must build its config there.

**On-device user data:** `PrescriptionHistoryService` (photos are copied to app storage), `ReminderService` (`flutter_local_notifications`, daily inexact alarms, no notifications on web) and `HealthProfileService` (allergies). These are `ChangeNotifier` singletons that the UI listens to with `ListenableBuilder`. `SpeechService` is one too: read aloud toggles play/pause, and resumes from the last word the engine reported.

**Map ([lib/widgets/universal_map_view.dart](lib/widgets/universal_map_view.dart)):** one OpenStreetMap view on every platform (touch pan/pinch/double-tap, buttons, markers), no key or billing. `google_maps_flutter` was removed because the Maps SDK requires a Google billing account. CARTO's keyless tiles return a watermark; OSM's tile policy fits light use, so switch to a tile provider before heavy traffic.

## Localization

ARB files live in `lib/l10n/` with `app_en.arb` as the template. The generated files are committed. Use `context.l10n.<key>`, or the inline `_t(en:, ar:)` / `isArabic ? ar : en` pairs that screens already use. Always provide both languages. `tr.isArabic` is the only helper left in [lib/localization/localization_extension.dart](lib/localization/localization_extension.dart).

## Theming

Use `PharmaLensTheme.paletteOf(context)`, `PharmaLensColors`, `PharmaLensDecorations` and the shared widgets in `responsive.dart`, not raw colors. Every screen must work in light and dark mode, in RTL, and at phone, tablet and desktop widths. [test/app_shell_test.dart](test/app_shell_test.dart) fails on layout overflow.

## Conventions

- Older files use a very vertical formatting style that does not match `dart format`. Match the style of the file you're editing and don't reformat whole files. New files use normal Dart formatting.
- Log errors through a local `_debugLog` or `debugPrint`, and show users friendly messages only.
- `showGeneralDialog` adds no `Material` ancestor (bottom sheets do): wrap its content in `Material(type: MaterialType.transparency)`. The same applies to an `ExpansionTile`/`ListTile` placed directly on a colored box.
- The pubspec SDK floor is `>=3.0.0`, so wildcard `_` parameters can't be repeated. Name them (`context, error, stackTrace`).
